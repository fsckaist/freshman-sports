# 시드 데이터 예시

이 폴더는 Git으로 관리되는 예시 파일 모음입니다.

- `user_demo.csv`, `bracket_demo.csv`: 시드 스크립트가 읽는 CSV 형식 예시
- `user_demo.xlsx`, `bracket_demo.xlsx`: CSV를 편집·검토하기 위한 Excel 형식 예시

실제 시드 스크립트는 이 디렉터리를 읽지 않습니다. 레포지토리와 독립된 상위 경로의 `../data`에 CSV를 복사해 사용하세요. 자세한 폴더 배치는 [구축 및 실행 방법](../../docs/setup-and-running.md)을 참고하세요.
